# AI 리더스 아카데미 지원센터

교육 과정에서 **과제를 받고, 목록으로 보고, 제출자가 직접 수정·삭제하게** 하고
**회원끼리 우수작에 투표**하고 **강의자료를 배포**하는 회원제 웹사이트입니다.
화면은 빌드 도구 없이 순수 HTML·CSS·ES 모듈로 되어 있고,
회원·제출물·파일은 Cloudflare Worker + R2 가 맡습니다.
데이터베이스는 쓰지 않습니다 — 회원 명부도 R2 안의 JSON 한 파일입니다.

디자인은 첨부해 주신 스타벅스 디자인 시스템 문서를 따랐습니다 —
따뜻한 크림 캔버스, 4단계 그린 체계, 50px 풀-필 버튼, 겹겹이 쌓은 옅은 그림자,
우하단에 떠 있는 원형 Frap 버튼.

## 무엇이 되나요

**교육생 (회원)**
- 기관명·성명·이메일·비밀번호로 **한 번 가입** — 승인 절차 없이 바로 이용
- 프로젝트 목록에서 과제 선택 — 한 행에 2개씩 배치
- 제출은 제목·설명·첨부파일만 — 참석자 정보는 계정에서 자동으로 붙습니다
- 이미지·동영상·문서 드래그&드롭 업로드 (형식·크기·개수 자동 검증)
- `내 제출물` 에서 자기 제출물을 언제든 확인·수정·삭제 (마감 전까지)
- 남의 제출물은 목록에도 상세에도 나오지 않습니다

**소통방**
- 회원이면 누구나 글을 남기고 서로 댓글을 달 수 있는 게시판
- 관리자가 **공지로 지정**한 글은 언제나 목록 맨 위 (금색 배지 + 왼쪽 띠)
- 내가 쓴 글·댓글만 수정·삭제, 관리자는 전부 정리 가능
- 제목·내용·작성자 검색, 본문의 주소는 자동으로 링크

**과제 투표**
- 상단 메뉴 `과제 투표` → 관리자가 투표를 연 과제가 진행중 · 예정 · 마감으로 나뉘어 보입니다
- 과제를 고르면 제출된 작품이 카드(첨부 이미지·영상은 썸네일)로 펼쳐집니다
- 1인당 정해진 표만큼 투표, 기간 안에는 취소하고 다시 넣기 자유
- 본인 작품에는 투표할 수 없습니다 (관리자가 허용하면 예외)
- **마감 뒤에 등록된 제출물은 투표에 올라오지 않습니다** — 같은 기간에 맞춰 낸
  작품들과 나란히 겨루는 것이 아니기 때문입니다
- **누가 어디에 표를 줬는지는 서버만 압니다** — 브라우저로는 집계와 "내 표"만 내려갑니다
- 투표 중 득표수를 감출 수 있고, 마감되면 자동으로 공개됩니다

**강의자료**
- 상단 메뉴 `강의자료` → 로그인한 회원이면 바로 목록
- 한 행에 2칸, 설명에 주소를 적으면 `바로가기` 버튼이 새 창으로 열립니다
- 파일 주소를 그대로 복사해 가도 로그인하지 않은 브라우저에서는 열리지 않습니다

**관리자**
- 프로젝트 개설·편집·삭제 (마감일시, 접수 상태, 공개 범위, 기관명 필수 여부, 첨부 허용 여부)
- **마감된 과제에도 등록 가능** — 늦게 받은 과제를 대신 올릴 수 있습니다.
  그렇게 들어간 제출물은 `마감 후 등록` 으로 표시되고 투표에서 빠집니다
- **다른 회원 이름으로 등록** — 제출 화면에서 제출자를 고르면 그 사람의 제출물이
  됩니다(그 회원의 `내 제출물`·제출 현황에도 잡힙니다). 누가 대신 올렸는지는 기록에 남습니다
- **상호 투표 설정** — 프로젝트마다 투표 사용 여부·기간·1인당 표 수·본인 투표 허용·득표수 공개 시점
- 제출물 관리 표와 CSV 에 득표수 열 (득표순 정렬)
- 강의자료 등록·편집·삭제 (PDF·PPT·ZIP, 자료당 10개까지, 개당 50MB)
- 전체 제출물 표 — 검색·정렬, 첨부 미리보기, 강제 삭제
- **제출 현황** — 프로젝트별로 제출자와 미제출자를 갈라 보고, 미제출자 이메일을
  한 번에 복사, 화면 그대로 CSV 내려받기 (관리자·정지 회원은 기본으로 제외)
- **수강 현황** — 온라인 6회차·오프라인 2회차의 출석과 과제 제출을 한자리에서
  (아래 별도 절)
- 소통방 공지 지정·해제, 남의 글·댓글 삭제
- **회원 관리** — 검색, 관리자 승격·해제, 이용 정지·해제, 비밀번호 초기화,
  **이용 정지된 회원 삭제**(제출물은 남길지 함께 지울지 선택), CSV 내려받기
  (정지된 회원은 목록 맨 아래로 내려가고, 대시보드 회원 수에서도 빠집니다)
- 전체 백업 JSON 내보내기 / 복원
- 저장소 모드 전환

### 관리자 계정 만들기

관리자 비밀번호는 어디에도 하드코딩돼 있지 않습니다.
**`aireader@mois.go.kr` 로 회원가입하면 그 계정이 관리자가 됩니다.** 비밀번호는 그때 정합니다.

배포 후 가장 먼저 이 계정으로 가입하세요. 다른 사람이 먼저 가입해 버리는 것을 막으려면
Worker 의 `ADMIN_EMAILS` 환경변수에 원하는 주소를 넣어두면 됩니다 (쉼표로 여러 개).
이미 가입한 회원을 관리자로 올리는 것은 `관리자 → 회원 관리` 에서 가능합니다.

## 배포 — Cloudflare Pages + R2 (현재 구성)

1. 이 브랜치를 `main` 에 머지합니다.
2. Cloudflare 에서 **R2 버킷을 하나 만들고**, Pages 프로젝트에 `BUCKET` 이름으로 바인딩합니다.
3. 끝입니다. `functions/api/[[path]].js` 가 함께 배포되어 `/api` 가 살아납니다.

버튼 하나하나까지 적어둔 순서는 **[docs/SETUP.md](docs/SETUP.md)** 에 있습니다.

> **푸시했는데 사이트가 안 바뀐다면** — Cloudflare 의 Git 연동은 프로덕션 브랜치에
> 푸시했을 때만 실제 배포를 하고, 그 밖의 브랜치는 버전만 만들어 둡니다(목록에는
> 똑같이 커밋이 찍힙니다). `Settings → Builds` 의 Production branch 와 Deploy command
> 를 확인하거나, `.github/workflows/deploy.yml` 로 GitHub Actions 가 직접 배포하게
> 하세요 — [docs/SETUP.md](docs/SETUP.md#푸시했는데-사이트가-안-바뀔-때) 참고.

## 저장소 모드

정적 사이트에는 서버가 없으므로 "데이터를 어디에 쓸 것인가"를 골라야 합니다.
세 가지를 지원하고, 관리자 화면에서 언제든 전환할 수 있습니다.

| 모드 | 설정 | 여러 사람 제출 | 파일 한도 | 데이터 위치 |
|---|---|---|---|---|
| **Cloudflare R2** (기본·권장) | 버킷 바인딩 1개 | **✓** 토큰 불필요 | 100MB/파일 | R2 버킷 |
| GitHub 저장소 | 토큰 또는 프록시 | 프록시 있을 때만 | ~25MB/파일 | 이 레포 |
| 브라우저 저장 | 없음 | ✗ | — | 각자의 IndexedDB |

### 왜 R2 인가

브라우저는 R2 를 직접 만지지 않습니다. 같은 도메인의 `/api` 만 호출하고,
버킷 권한은 Cloudflare 바인딩으로만 존재합니다. 그래서

- **비밀값이 브라우저로 내려가지 않습니다.** 교육생에게 토큰을 나눠줄 필요가 없습니다.
- **CORS 설정이 없습니다.** 사이트와 API 가 같은 오리진입니다.
- **큰 파일이 올라갑니다.** GitHub Contents API 의 base64 인코딩(용량 +33%)과
  레포 비대화 문제가 사라집니다.
- **레포가 깨끗합니다.** 제출물이 커밋으로 쌓이지 않습니다.

## 데이터 구조

R2 모드에서 버킷 안은 이렇게 생겼습니다.

```
data/projects.json             프로젝트 배열
data/submissions.json          제출물 메타데이터 배열
data/materials.json            강의자료 메타데이터 배열
data/posts.json                소통방 글 + 댓글
data/votes.json                상호 투표 — 표 한 줄씩 (투표자는 서버에만)
data/roster.json               수강생 전체 명단 (관리자만)
data/attendance.json           회차별 출석·과제 제출 (관리자만)
uploads/<제출ID>/<파일>         과제 첨부 원본
uploads/materials/<자료ID>/…   강의자료 원본
```

색인 파일은 **etag 기반 조건부 쓰기**로 갱신합니다. 동시에 제출이 겹쳐 etag 가
어긋나면 서버가 409 와 함께 최신본을 실어 보내고, 클라이언트가 그 위에 다시 적용해
최대 5회까지 재시도합니다. 그래서 동시 제출에서 한쪽이 조용히 사라지지 않습니다.

### 저장소 API (`/api`)

| 경로 | 하는 일 |
|---|---|
| `GET /api/health` | 상태 · 로그인 여부 · 업로드 한도 |
| `POST /api/auth/signup` · `login` · `logout` | 가입 · 로그인 · 로그아웃 |
| `GET /api/auth/me` | 현재 세션의 회원 정보 |
| `POST /api/auth/password` | 비밀번호 변경 |
| `POST /api/auth/forgot` | 비밀번호 재설정 요청 접수 (로그인 불필요). `method:'code'` 면 숫자 6자리 임시 비밀번호를 그 자리에서 돌려줍니다 (30분 유효) |
| `POST /api/auth/reset/confirm` | 재설정 링크(토큰)로 새 비밀번호 설정 (로그인 불필요, 1회용) |
| `GET`·`PATCH /api/auth/members` | 회원 목록 · 권한/상태 변경 (관리자) |
| `DELETE /api/auth/members` | 이용 정지된 일반 회원 삭제 (관리자) |
| `POST /api/auth/members/reset` | 임시 비밀번호 발급 (관리자) — 숫자 6자리 · 30분 |
| `GET /api/data/:name` | 프로젝트·강의자료 색인 읽기 (회원) — `roster`·`attendance` 는 관리자만 |
| `PUT /api/data/:name` | etag 조건부 색인 쓰기 (관리자) |
| `GET`·`POST /api/submissions` | 내 제출물 목록 · 제출 (제출자 정보는 서버가 채웁니다). 마감 뒤에는 관리자만 등록할 수 있고 `late` 가 붙습니다. 관리자는 `authorEmail` 로 다른 회원 이름으로 등록할 수 있습니다(`registeredBy` 기록) |
| `PATCH`·`DELETE /api/submissions/:id` | 본인 또는 관리자만 |
| `PUT /api/submissions` | 백업 복원 — 제출물 색인 통째로 교체 (관리자) |
| `GET`·`POST /api/posts` | 소통방 목록(공지 우선) · 글쓰기 |
| `PATCH`·`DELETE /api/posts/:id` | 본인 또는 관리자 — 공지 지정은 관리자만 |
| `POST /api/posts/:id/comments` | 댓글 달기 |
| `DELETE /api/posts/:id/comments/:cid` | 본인 또는 관리자 |
| `GET /api/votes?projectId=…` | 투표 집계 + 내가 넣은 표 (남의 표는 안 내려갑니다) |
| `POST /api/votes` | 표 넣기·빼기 — 기간·1인당 표 수를 서버가 확인 |
| `POST /api/upload` | 파일 업로드 (저장 위치는 서버가 결정) |
| `GET /api/file/<key>` | 파일 스트리밍 (회원) |
| `DELETE /api/file/<key>` | 파일 삭제 (관리자) |
| `POST /api/telegram/webhook` | 텔레그램 알림 · 재설정 버튼 콜백 (텔레그램 서버 전용, [Hermes](docs/SETUP.md#d-hermes--텔레그램-알림-선택)) |

회원 명부(`data/members.json`)는 `/api/data/*` 로 절대 내려오지 않고,
비밀번호는 PBKDF2-SHA256 해시로만 저장됩니다(원문은 어디에도 남지 않습니다).
비밀번호는 **8자 이상 + 문자·숫자·특수문자 모두 포함**이어야 하며,
가입·변경·재설정 링크 어느 경로로 정해도 같은 정책이 적용됩니다. 세션은 HMAC 으로 서명한
**HttpOnly 쿠키**라 자바스크립트로 읽거나 위조할 수 없습니다.

> **API 는 사이트와 같은 도메인이어야 합니다.** 세션 쿠키가 `SameSite=Lax` 라서,
> 등록 도메인이 다른 곳(사이트는 `pages.dev`, API 는 `workers.dev` 같은 조합)으로는
> 쿠키가 전달되지 않아 로그인 직후부터 401 이 납니다. 기본값 `/api` 를 그대로 쓰세요.
> 어긋나면 브라우저 콘솔과 관리자 → 저장소 패널에 경고가 뜹니다.

업로드된 파일은 항상 `X-Content-Type-Options: nosniff` 와
`Content-Security-Policy: default-src 'none'; sandbox` 를 달고 나갑니다.
이미지·PDF·동영상만 인라인으로 열리고 나머지(SVG·HTML 포함)는 첨부로 강제되므로,
업로드된 파일이 우리 도메인에서 스크립트를 실행할 수 없습니다.

## 수강 현황 — 출석·과제 관리

`관리자 → 수강 현황`. 과제 제출 시스템과 **따로 도는** 출결 장부입니다.
회원 가입 여부와 무관하게, 강의를 듣는 사람 전체를 명단으로 두고
회차마다 출석과 과제 제출을 기록합니다.

### 회차

온라인 6회차(8.25 · 9.8 · 9.29 · 10.13 · 11.17 · 12.8)와 오프라인 2회차,
모두 8회차입니다. 오프라인 회차는 일자가 비어 있고, `회차 정보 수정` 에서
주제와 일자를 정하면 됩니다. 온라인 회차의 주제·일자도 같은 방법으로 고칩니다.

### ① 전체 명단 — 한 번만 올립니다

이름과 소속이 든 **CSV 또는 XLSX** 파일을 올리면 `이름`·`성명`·`성함` 과
`부서`·`소속`·`기관` 열을 스스로 찾아 표로 정리합니다. 머리글을 못 찾으면
어느 열인지 물어봅니다(맨 위 몇 줄을 보여줍니다).

- **동명이인은 소속으로 구분합니다.** 같은 이름이 둘 이상이면 화면에 안내가 뜨고,
  이후 모든 화면에서 `이수현 (교육부)` 처럼 소속을 붙여 부릅니다.
- 명단을 **다시 올려도** 이름과 소속이 같은 사람은 기존 항목을 그대로 이어씁니다 —
  지금까지 쌓은 출결이 남습니다. 새 파일에 없는 사람은 명단에서 빠지는데,
  출결 기록이 있으면 몇 명이 사라지는지 먼저 알려주고 확인을 받습니다.
- 한 명씩 직접 추가·수정·삭제할 수도 있습니다.

### ② 회차별 기록 — 파일을 올리거나 직접 체크하거나

회차를 고르고 **출석자 명단**과 **과제 제출자 명단**을 각각 올립니다.

**Zoom 접속기록을 그대로 올려도 됩니다.** 표시 이름이 `부서명_이름` 이면
이름만 뽑아 명단과 맞춥니다. 위쪽에 회의 정보가 몇 줄 붙어 있어도 머리글을 찾아냅니다.
`홍길동의 iPhone`, `행안부_홍길동 (홍길동)`, `행정안전부홍길동` 처럼
기기 이름이나 괄호가 붙거나 구분자가 없어도 찾아냅니다.

스스로 정하지 못한 것만 **팝업으로 물어봅니다.**

| 상황 | 처리 |
|---|---|
| 동명이인인데 표시 이름에 소속이 함께 있음 | 소속으로 자동 구분 (묻지 않습니다) |
| 동명이인인데 소속을 알 수 없음 | 팝업에서 해당하는 사람을 고릅니다 (여러 명 선택 가능) |
| 명단에 없는 이름 | 팝업에서 체크하면 명단에 새로 넣고 이번 회차에도 반영합니다 |

파일 내용으로 **교체**할지, 이미 있는 기록에 **더할지**도 팝업에서 고릅니다
(접속기록을 나눠서 받았을 때 씁니다).

**파일 없이도 됩니다.** 같은 화면 아래의 체크리스트에서 출석·제출을 직접 켜고 끄고,
`전체 출석` 같은 버튼으로 한 번에 처리한 뒤 저장하면 됩니다. 파일로 올린 뒤
몇 명만 손보는 것도 여기서 합니다. `결석자만` 필터로 처리할 사람만 추려 볼 수 있습니다.

### ③ 대시보드 · 학생별 상세 · 엑셀

- **대시보드** — 전체 인원, 평균 출석률·제출률, 회차별 현황, 학생 × 회차 전체 표
  (○ 완료 · × 미완료 · – 아직 기록 안 함), 그리고 **주의가 필요한 학생** —
  한 회차라도 결석과 미제출이 겹친 사람입니다.
- **학생별 상세** — 이름이나 소속으로 찾아 8회차 전체 출석·제출 이력을 봅니다.
- **엑셀로 내보내기** — `학생별 상세`(한 줄에 한 명, 회차마다 출석·제출 두 칸)와
  `회차별 요약`(인원·비율) 두 장짜리 `.xlsx` 를 내려받습니다.

> 출석률·제출률의 분모는 **기록된 회차**뿐입니다. 아직 하지 않은 회차가
> 결석으로 잡히지 않습니다.

명단과 출결은 `data/roster.json` · `data/attendance.json` 에 담기고
**관리자만 읽고 쓸 수 있습니다**(교육생 전원의 이름과 소속이 모인 자료이므로,
프로젝트·강의자료 색인과 달리 회원에게도 내려가지 않습니다).
전체 백업 JSON 에도 함께 담깁니다.

CSV·XLSX 를 읽고 쓰는 코드는 `assets/js/sheet.js` 에 직접 넣었습니다 —
빌드 도구도 CDN 도 쓰지 않는 이 사이트의 방식을 지키기 위해서입니다.
(엑셀 파일은 XML 몇 장을 담은 ZIP 이라 브라우저의 `DecompressionStream` 으로 풉니다.)

| 부정 사용 차단 | `관리자 → 회원 관리 → 이용 정지` (열려 있던 세션도 즉시 끊깁니다) |
| 회원 지우기 | 먼저 `이용 정지` → 목록 맨 아래로 내려간 그 행에서 `삭제`. 실수를 막으려고 **이용 정지된 일반 회원만** 지울 수 있습니다 — 관리자를 지우려면 권한을 먼저 해제하세요. 제출물은 기본적으로 남고(프로젝트의 기록이므로), 지울지는 삭제할 때 고릅니다. 그 사람이 넣은 표는 언제나 함께 지워집니다 |

### 비밀번호 찾기 — 두 갈래

`비밀번호를 잊으셨나요?` 화면에서 교육생이 직접 고릅니다.

| 방법 | 무슨 일이 생기나 | 언제 쓰나 |
|---|---|---|
| **관리자에게 요청** (기본) | 관리자 대시보드·회원 관리에 대기로 뜨고, 텔레그램([Hermes](docs/SETUP.md#d-hermes--텔레그램-알림-선택))을 켰다면 알림이 갑니다. 알림에는 **본인이 새 비밀번호를 직접 정하는 1회용 링크**(60분 유효)가 담기니, 그 링크를 신청자에게 전달하면 비밀번호가 아무에게도 노출되지 않습니다. 급하면 알림의 버튼이나 `회원 관리 → 비밀번호 초기화` 로 임시 비밀번호를 그 자리에서 발급할 수도 있습니다. 메일 발송을 붙였다면([docs/SETUP.md](docs/SETUP.md) "E") 본인 메일로 링크가 바로 갑니다 | 평소 |
| **임시 비밀번호 즉시 받기** | 숫자 6자리를 그 화면에 바로 띄웁니다. **30분** 동안만 살고, 그것으로 로그인하면 곧바로 새 비밀번호를 정하는 화면이 열립니다. 5분 안에 다시 요청하면 거절하고, 발급 사실은 텔레그램으로 관리자에게 남습니다 | 텔레그램이 멈췄거나 관리자가 자리에 없을 때 |

임시 비밀번호는 어느 길로 받든 **숫자 6자리 · 30분 · 로그인하면 곧바로 변경**으로
같습니다. 전화로 불러주기 좋으라고 숫자만 씁니다. 조합이 100만 가지뿐이라
짧은 수명 · 8회 실패 잠금 · 강제 변경 셋을 함께 걸어 씁니다.

> **알아 두실 것 — 즉시 발급은 이메일만 알면 누구나 누를 수 있습니다.**
> 남의 이메일로 눌러 그 사람의 비밀번호를 6자리로 갈아 끼울 수 있다는 뜻입니다
> (번호는 누른 사람 화면에 뜨므로 계정을 가져갈 수도 있습니다). 관리자 경로가
> 막혔을 때의 **예비 수단**으로 두시고, 평소에는 관리자 경로를 쓰세요. 발급될
> 때마다 텔레그램 알림이 가니, 짚이는 게 없는 알림이 오면 회원 관리에서 그
> 계정을 정지시키면 됩니다.

비밀번호를 바꾸거나 관리자가 초기화하면 **그 계정의 다른 세션이 전부 끊깁니다.**
계정을 도난당했을 때 상대 기기가 남은 12시간을 그대로 쓰지 못하게 하기 위한 것입니다.
(정지했다가 다시 푼 계정도 마찬가지로 예전 세션은 되살아나지 않습니다.)

**솔직한 한계**

- **자체 메일 서버가 없습니다.** 이메일 인증은 없고, 비밀번호 재설정 메일은
  관리자의 Google 계정(Apps Script)을 발송 창구로 연결했을 때만 자동 발송됩니다
  ([docs/SETUP.md](docs/SETUP.md)의 "E. 메일로 재설정 링크 자동 발송").
  설정하지 않으면 교육생의 요청이 관리자 화면 대기 목록·텔레그램 알림으로만 오고,
  관리자가 재설정 링크나 임시 비밀번호를 직접 전달합니다.
- **가입은 누구나 즉시** 가능합니다. 아무나 못 들어오게 하려면 회원 관리에서
  정지시키거나, `ADMIN_EMAILS` 처럼 가입 허용 도메인을 서버에 추가해야 합니다.
- **브라우저 저장 · GitHub 모드의 회원 기능은 시연용**입니다. 검증이 브라우저에서
  일어나므로 우회할 수 있습니다. 실제 운영은 반드시 R2 모드로 하세요.
  (화면에도 "시연용"이라고 표시됩니다.)
- **텔레그램 알림(Hermes)을 켰다면**, 그 채팅에 들어와 있는 사람은 누구든
  재설정 링크를 보고 버튼으로 임시 비밀번호를 발급할 수 있습니다. 신뢰하는 관리자만
  초대하세요 — 자세한 설정은 [docs/SETUP.md](docs/SETUP.md)의 "D. Hermes".
- **임시 비밀번호 즉시 발급은 이메일만 알면 누를 수 있습니다.** 관리자 경로가
  막혔을 때를 위한 예비 수단입니다 — 위 "비밀번호 찾기 — 두 갈래" 를 보세요.

## 로컬에서 확인하기

`/api` 가 없는 환경에서는 R2 모드가 뜨지 않습니다. 두 가지 방법이 있습니다.

**① 실제 R2 로 (권장)** — Cloudflare 계정에 붙여 그대로 돌립니다.

```bash
npx wrangler pages dev . --r2=BUCKET
```

**② R2 없이 화면만** — 정적 서버를 띄운 뒤 브라우저 콘솔에서 모드를 바꿉니다.

```bash
python3 -m http.server 8000
# 접속 후 콘솔에서:  localStorage.setItem('ah.storageMode','local'); location.reload()
```

관리자 화면 하단 **저장소** 패널에서도 모드를 바꿀 수 있습니다.

## 접근성·호환성

- 키보드만으로 전체 흐름 사용 가능 (건너뛰기 링크, 포커스 트랩, `aria-*`)
- 폼 오류는 `aria-invalid` + 텍스트로 함께 안내
- `prefers-reduced-motion` 존중
- 375px 모바일에서 가로 스크롤 없음 · 넓은 표는 자체 스크롤
- 인쇄 시 네비게이션·버튼 숨김
- 320px~1600px 전 구간에서 가로 스크롤 없음 (테스트로 검증)
- 업로드 파일은 sandbox CSP + nosniff 로 제공 — 우리 도메인에서 스크립트 실행 불가
- 세션 쿠키는 HttpOnly · SameSite=Lax · Secure — 스크립트가 읽을 수 없음
- Chrome·Edge·Safari·Firefox 최신 버전 기준
