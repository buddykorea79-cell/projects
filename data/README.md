# data/

GitHub 저장소 모드에서 이 폴더가 데이터베이스 역할을 합니다.

| 파일 | 내용 |
|---|---|
| `projects.json` | 개설된 프로젝트 배열 |
| `submissions.json` | 제출물 메타데이터 배열 (첨부 원본은 `uploads/`) |
| `materials.json` | 강의자료 메타데이터 배열 (파일 원본은 `uploads/materials/`) |
| `evaluations.json` | 평가 투표용지 배열 — 프로젝트별로 관리자 한 사람당 한 장 |

모든 파일을 앱이 자동으로 커밋합니다. 손으로 고칠 일은 거의 없지만,
고칠 때는 반드시 **올바른 JSON 배열**을 유지하세요. 파일이 깨지면 목록이 비어 보입니다.

백업은 관리자 대시보드의 **전체 백업 내려받기** 버튼을 쓰는 편이 안전합니다.
